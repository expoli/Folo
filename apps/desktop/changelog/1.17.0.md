# What's new in v1.17.0

## New

- The local AI chat now reads unread entries and article text through the same read-only tools the local MCP endpoint exposes, so an answer is no longer limited to entries the panel already loaded
- Chat can use the MCP services enabled in Settings -> AI -> MCP; a tool that cannot claim to be read-only is offered as an approval request, and Allow runs it while Deny does not
- Added `folo_unread_digest`, which reads a whole unread window (`today`, `yesterday`, `last24h` or `last7d`) with bounded excerpts in one call and reports each source's coverage

## Improvements

- The unread-only scope is a switch in the chat panel now; the timeline filter only seeds it when the panel opens, so a later change to the list no longer rewrites the scope of a conversation in progress
- A chat continues on its own after a tool call is allowed or denied
- Reading the panel through the chat's own tools does not require exposing the local MCP port

## No longer broken

- Fixed chat continuations losing their source scope, date bounds and selected scenes
- Fixed article text and summary provenance being dropped or fetched again between turns
- Fixed an AI endpoint that does not support tool calling failing every chat, instead of being remembered and used without tools
- Fixed an unpackaged desktop build taking over the installed app's login callbacks
