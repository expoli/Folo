# What's new in v1.17.1

## New

- New "Autoplay videos" setting in General: turn it off and YouTube and Bilibili embeds, hover previews and media previews wait for a click before playing
- The mobile reader lays out next to the list on iPad, with previous and next entry controls

## Improvements

- Changes made offline or while the server is unreachable are kept and sent when the connection is back; only changes the server refuses are undone, with the reason shown
- A feed without stored entries says it is offline instead of loading forever
- Find in page keeps every keystroke, steps through matches in order and leaves no highlights behind after closing
- RSSHub routes that need a paid plan show an upgrade button in the follow form instead of a fetch error
- Editing Actions on two devices no longer overwrites the other device's rules
- Clearer, translated errors for sign-in, the follow form and an unreachable server
- AI replies wait as long as the server does and end with the server's error in your language
- Saving media suggests a clean file name
- Removed plural variants the Japanese and Chinese translations never use

## No longer broken

- Fixed a new device or browser replacing the account's AI shortcuts with the built-in ones
- Fixed the previous account's settings, including AI provider keys and MCP headers, being uploaded to another account that signed in on the same device
- Fixed signing out or switching accounts reopening the last entry, which the next account then marked as read
- Fixed changes queued under an expired session being sent with the next account's session
- Fixed stars and read marks made offline doing nothing and getting lost on reload
- Fixed unread counts after a refused Mark all as read, a deleted list or a feed removed from a list
- Fixed folder renames and subscription edits undoing changes made on other devices
- Fixed saved regex patterns such as (?i)foo blocking every later save of Actions
- Fixed push notifications stopping after a failed token upload until the next sign-in
- Fixed MCP authorization reporting a blocked popup
- Fixed folo:// links with unknown paths opening hidden windows that never closed
- Fixed the follow form saying "Updated" after a first follow instead of "Followed"

This build also carries everything from v1.17.0: the local AI chat with read-only reading tools and tool approvals, the local MCP endpoint, and this fork's own desktop updater.
