# What's new in v1.16.0

## New

- Let external local AI agents read unread entries and article text through a read-only MCP endpoint while Folo Desktop is running and signed in
- Enable the endpoint in Settings -> Integration -> Local agent reading (MCP), then connect a Streamable HTTP client to `http://127.0.0.1:41610/mcp` with the dedicated token
- Scan unread entries across supported views and inboxes, page through the candidate list, and read cached text or fetch article details without marking entries read
- Fetch public article pages only after enabling a separate permission, which is off by default

## Safety and coverage

- Both the endpoint and article-page fetching start disabled; access requires a revocable token and is restricted to the local machine
- Account isolation, request limits, guarded article fetching, and sanitized error messages protect account data
- Text responses identify their source and completeness, report per-entry failures, and support continuation for long text
- Scans explicitly report partial coverage at unverified timestamp-based pagination boundaries or resource limits; they are best-effort selections, not guaranteed snapshots of all unread entries

Summarization runs in the external agent. A local MCP connection does not imply that the agent's model is local; check its data-handling settings before sending article text to a cloud model.

See [the local agent reading guide](https://github.com/expoli/Folo/blob/v1.16.0/docs/local-agent-reading.md) for setup, permissions, limits, and verification details.
